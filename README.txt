RideX — версия для Windows 10/11 (64 бита, Intel/AMD)

1. Распакуй ВЕСЬ архив в обычную папку, например «Документы\RideX».
2. Дважды щёлкни START_RideX.bat. Сайт откроется в браузере.
3. Не закрывай открывшееся окно, пока пользуешься сайтом.
4. Чтобы остановить сервер, закрой окно или нажми Ctrl+C.

Устанавливать Python, Node.js и базу данных не нужно. Интернет для запуска не нужен.
Если браузер не открылся: http://127.0.0.1:8765
Запускай сайт через START_RideX.bat, а не через index.html.
При повторном запуске сначала закрой предыдущее окно RideX.

Работают регистрация, вход, личный кабинет и выход.
Вход сохраняется до 7 дней, в том числе после перезапуска сервера.
Почта приводится к нижнему регистру. Пароль: от 8 до 128 символов.
После 15 попыток регистрации/входа за минуту нужно немного подождать.

Аккаунты и сессии хранятся в data\ridex.sqlite3, которая появится при первом запуске.
Пароли сохраняются как PBKDF2-SHA256 хеши с отдельной случайной солью.
Для резервной копии закрой сервер и скопируй папку data.
Не удаляй data: это удалит аккаунты. Не передавай свою папку data другим людям.

Каталог, корзина и избранное работают как раньше: корзина и избранное
сохраняются в браузере и общие для аккаунтов в этом браузере.
Заказы остаются демонстрационными. Оплаты, писем и восстановления пароля нет.
Это локальная учебная версия. Сервер доступен только на этом ноутбуке;
для публикации в интернете потребуется отдельная подготовка.

Исходный бэкенд: server.py. Проверка: python tests/test_auth.py
В runtime включён официальный Python 3.13.7 Windows embeddable (x64):
https://www.python.org/downloads/release/python-3137/
Лицензия Python: runtime/LICENSE.txt.
